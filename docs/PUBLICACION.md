# Comprobaciones para publicar una APK

- [ ] Código fuente público y licencia libre.
- [ ] Dependencias y licencias verificadas.
- [ ] APK compilada desde una etiqueta de versión.
- [ ] APK firmada; clave privada fuera del repositorio.
- [ ] Hash SHA-256 publicado.
- [ ] Permisos Android mínimos y documentados.
- [ ] Sin publicidad, rastreadores ni SDK de analítica.
- [ ] Pruebas en dispositivo real.
- [ ] Descripción honesta de las conexiones de red, si las hay.
- [ ] Enlaces a código, versión y descarga comprobados.
